# PHYSICS.md — допущения и границы

WellGuard OS использует **упрощённые, физически мотивированные признаки**, не полную электро-гидравлическую модель ЭЦН.

## Признаки
- **head_coef** = (intake_p − whp) / (freq/50)² — коэффициент напора по закону подобия (H ~ f²). Падение — признак газа/срыва.
- **q_per_freq** = q / (freq/50) — подача на единицу частоты (Q ~ f). Устойчивое падение — признак засорения приёма.
- **current_per_q** = current / |q| — удельный ток (прокси плотности/обводнённости).
- **current_var** — локальная изменчивость тока (газовые пробки).

## Чего модель НЕ делает
- не решает полную гидравлику скважины/многофазность;
- не моделирует PVT, газовый фактор явно;
- пороги настроены на синтетике и требуют переоценки на архиве заказчика;
- не является средством противоаварийной защиты.
