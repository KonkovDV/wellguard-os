# CLAIM_FREEZE.md — границы публичных утверждений

Отправленное письмо в INDUSTRIX 2026 фиксирует **публичный периметр утверждений**.
Этот файл — внутренний стоп-кран для разработки и документации.

## Разрешено усиливать (без новых обещаний)

- QC, timeline, units, fail-closed поведение
- physics-guided признаки и уже названные классы событий
- карточка события, heuristic score (не вероятность), output limits
- CLI / read-only API / read-only UI / Docker loopback
- синтетический генератор, red-team / pytest / CI
- 3W Dataset 2.0.0 local loader + SHA-256
- контракт обезличенного архива и shadow replay journal
- документацию ограничений, пилота, threat model

## Запрещено заявлять без новой явной редакции письма

- полевую точность, экономический эффект, предотвращение аварий
- управление оборудованием / запись в АСУ ТП / СУЗ
- RUL / остаточный ресурс / подтверждение отказа
- новые классы событий или «автономную эксплуатацию»
- завершённую валидацию на 3W/архиве заказчика как свершившийся факт
- изменение состава минимальных входов или смысла классов из письма
