# PILOT_PLAN.md

Цель: проверить, сохраняется ли ценность на данных владельца осложнённого фонда.

| Этап | Срок | Содержание |
| --- | --- | --- |
| 1. Ретроспектива | 3–6 нед | Обезличенный архив куста ЭЦН против действующих тревог |
| 2. Адаптеры + калибровка | 4 нед | Маппинг тегов, переоценка порогов на архиве |
| 3. Shadow mode | 4–8 нед | Read-only, без воздействия на АСУ ТП, журнал решений |
| 4. Go/No-go | — | Сравнение с baseline, решение |

## KPI (согласуются с владельцем до старта)
- задержка обнаружения по подтверждённым событиям;
- precision/recall по размеченным событиям;
- ложные тревоги / смену относительно действующей схемы;
- доля полезных тревог по оценке технолога;
- отсутствие управляющих воздействий.

Денежный эффект не заявляется до пилота.
