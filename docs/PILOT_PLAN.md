# PILOT_PLAN.md

Цель: проверить, сохраняется ли ценность объяснимой карточки на данных владельца
осложнённого фонда. Формат совпадает с письмом INDUSTRIX: сначала архив, затем
read-only shadow, без подключения к управлению.

| Этап | Срок | Содержание |
| --- | --- | --- |
| 1. Ретроспектива | 3–6 нед | Обезличенный архив группы скважин ЭЦН, каналы/единицы/частота |
| 2. Адаптеры + разметка | 4 нед | Маппинг тегов, экспертная разметка эпизодов, суточные рапорты |
| 3. Калибровка на истории | — | Пороги только на согласованном историческом периоде |
| 4. Holdout | — | Проверка на отложенном интервале без перемешивания |
| 5. Shadow mode | 4–8 нед | Read-only, журнал карточек, экспертная оценка, без АСУ ТП |
| 6. Go/No-go | — | Продолжение / доработка / остановка |

## Последовательность работ (из письма)

1. Получение обезличенного архива одной группы скважин с ЭЦН.
2. Согласование состава каналов, единиц, частоты и правил пропусков.
3. Проверка временной шкалы и режимов работы.
4. Экспертная разметка эпизодов и записей из суточных рапортов.
5. Сравнение с действующими тревогами и текущим порядком разбора.
6. Настройка порогов только на согласованном историческом периоде.
7. Проверка на отложенном временном интервале без перемешивания.
8. Запуск локального режима только для чтения.
9. Ведение журнала карточек и экспертной оценки (`shadow` JSONL disposition fields).
10. Решение о продолжении, доработке или остановке.

## KPI (согласуются с владельцем до старта)

- ложные тревоги осложнений на скважину или смену;
- задержка до подтверждённого события;
- полнота и точность по экспертной разметке;
- правильность определения режима работы;
- устойчивость к пропускам, шуму и дрейфу каналов;
- доля карточек, признанных полезными технологом;
- время от устойчивого отклонения до первичной проверки;
- отсутствие управляющих воздействий;
- критерии остановки и перехода к следующему этапу.

Денежный эффект, полевая точность и готовность к автономной эксплуатации
**не заявляются** до завершения архивной проверки и shadow-режима.
